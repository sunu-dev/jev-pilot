Useful estimates. Clear boundaries.

A smaller number only matters if the work still gets done well.

The baseline prices the same observed tokens as each request's configured maximum-tier model. Net difference subtracts the model estimate and Jev cost. It doesn't rerun the task or measure subscription quota, quality, or money refunded.

Set up price estimates

Add current USD-per-million input, output and cache rates under prices in your global config, plus Jev's input rate under jevPrice. Start a new routed session after changing rates. Existing records keep their original estimates.

~/.config/jev-pilot/config.json

Use official rates for your exact models. Missing data stays unavailable; negative differences stay negative.
