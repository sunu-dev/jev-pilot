# GitHub 성장 조사와 Jev Pilot 공개 전략

조사일: 2026-10-10. 저장소 페이지와 GitHub REST API로 확인했습니다. 스타는 누적 수치이며 주간 신규 스타가 아닙니다. 수치는 변동합니다. 이 문서는 성공 원인의 인과 실험이 아니라 공개 자료에서 관찰한 공통점과 적용 가설입니다.

각 프로젝트의 범위·운영 기간·기존 사용자 기반이 다릅니다. 기능을 따라 만들면 동일한 스타를 얻는다는 뜻은 아닙니다. GitHub의 [커뮤니티 연구](https://github.blog/open-source/maintainers/healthy-and-sustainable-communities/)도 README, 첫 기여 이슈, 기여 가이드, 행동 강령 등 참여 구조를 강조합니다.

주간 Trending 화면은 단순 주간 신규 스타 순 정렬과 같다고 가정하면 안 됩니다. 이번 [웹 조회](https://github.com/trending?since=weekly)는 캐시된 과거 화면을 반환했으므로 현재 주간 1등이나 필요한 스타 수를 확정하지 않았습니다. “전체 언어 GitHub Trending 주간 상위권”을 목표로 삼되, 특정 순위나 시점을 보장하지 않습니다.

## Jev Pilot의 차별화 가설

‘가장 싼 모델로 바꿔준다’만으로는 기존 라우터와 구분하기 어렵습니다. 우리의 주제는 **‘내 구독 코딩 도구가 어떤 모델을 왜 사용했고, 실제로 무엇이 달라졌는지 확인한다’**입니다.

- 상위 모델 고정 문제를 재현하고 해결 과정을 보여줍니다.
- Jev 호출 횟수, 모델/추론 변경, 실제 응답 모델, 캐시와 실패를 한 화면에서 확인합니다.
- 구독 한도와 API 가격 추정을 구분합니다. 없는 숫자를 절감률로 만들지 않습니다.
- 원래 CLI를 덮어쓰지 않는 설치·제거, 키 없는 오프라인 테스트, 실패를 숨기지 않는 실제 검증을 제공합니다.

## 기능 우선 공개 순서

1. **알파 기능 검증:** CI, 설치/제거, 실제 두 CLI 연결, 민감정보 제외, 잘못된 응답/누락 사용량 처리.
2. **실사용 증거:** 작성자 이외 5–10명에게 자발적 설치 테스트를 요청하고 실패를 고칩니다. 공개적으로 공유 가능한 실제 작업에서 결과·재시도·캐시·시간을 함께 기록합니다. 현재 이 모집/검증은 완료되지 않았습니다.
3. **재현 가능한 비교:** 고정 모델 기준과 30개 이상의 독립 작업을 반복 비교합니다. 품질 실패를 제외하지 않고 공개합니다. API 추정치와 구독 잔여량 관측은 별도 표로 둡니다.
4. **설명 자료:** 30초 데모, 짧은 영문 README, 한국어 문서, 실제 보고서와 가상 데모의 명확한 구분, 한눈에 보는 호환표.
5. **집중 공개:** 검증된 첫 버전을 태그하고 관련 커뮤니티 규칙에 맞춰 제작자가 소개합니다. Hacker News Show HN, r/ClaudeCode, Codex 커뮤니티, 한국 개발 커뮤니티는 잠재 채널입니다. 실제 게시 전 각 채널의 현재 규칙을 확인합니다. 이 문서는 게시 승인이 아니며 자동으로 글을 보내지 않습니다.
6. **유지:** 설치 실패와 모델 오선택에 빠르게 답하고, 호환 업데이트와 공개 변경 기록을 남깁니다.

스타 구매·교환이나 반복 홍보를 성장 전략으로 삼지 않습니다. 사용자가 직접 체험하고 재현할 수 있는 가치가 공유의 근거여야 합니다.

## 측정할 지표

주간 신규 스타와 Trending 위치는 결과 지표로 두고, 먼저 설치 성공률·실제 검증 통과율·일주일 뒤 재사용·작업 완료율·수정 필요 횟수를 봅니다. 현재 중앙 수집 기능이 없으므로 설치율/재사용율은 동의한 테스트 참가자의 직접 응답 없이는 알 수 없습니다. 스타를 사용자 수로 환산하지 않습니다.

GitHub 공개는 시작이고 대규모 홍보는 별도 단계입니다. 현재 알파는 연결과 정책을 검증하는 도구이며, 토큰 절감이 입증된 제품으로 소개하지 않습니다.
